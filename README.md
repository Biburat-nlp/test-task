# speedtest.py

Консольный скрипт для измерения скорости скачивания по HTTP(S).

Скрипт делает 10 последовательных запросов к указанному адресу, каждый раз дочитывает ответ до конца, а затем выводит:

- время и объём каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- скорость скачивания.

## Требования

Python 3.8+. Сторонние библиотеки не нужны, используется только стандартная библиотека.

## Запуск

```bash
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py "https://speed.cloudflare.com/__down?bytes=5000000"
```

Количество запросов можно изменить флагом `-n` (по умолчанию 10):

```bash
python speedtest.py "https://speed.cloudflare.com/__down?bytes=5000000" -n 5
```

На Windows вместо `python` может понадобиться `py`.

## Пример вывода

```
Запрос  1: 1.31 MB за 0.412 с
...
Запрос 10: 1.31 MB за 0.398 с

Среднее время запроса: 0.405 с
Всего скачано: 13.11 MB (13107200 байт)
Скорость скачивания: 25.89 Мбит/с
```

## Единицы измерения

| Величина       | Единица   | Определение                     |
|----------------|-----------|---------------------------------|
| Время          | с         | секунды                         |
| Объём данных   | MB        | мегабайт, 1 MB = 1 000 000 байт |
| Скорость       | Мбит/с    | мегабит в секунду, 1 Мбит = 1 000 000 бит |

Скорость выражена в Мбит/с, потому что в этих же единицах обычно указывают скорость интернет-тарифов, и результат легко сравнить. Используются десятичные приставки (СИ), а не двоичные (MiB).

## Как считается

- Время запроса измеряется от его отправки до получения последнего байта тела ответа (включая установку соединения, TLS и ожидание первого байта).
- Среднее время запроса = сумма времени всех запросов / число запросов.
- Скорость = общий объём (в битах) / суммарное время всех запросов.
- Объём считается по фактически прочитанным байтам тела ответа, заголовки не учитываются.
- Каждый запрос открывает новое соединение и отправляет заголовок `Cache-Control: no-cache`, чтобы снизить влияние кешей.
- Принимаются только адреса `http://` и `https://`.
- Если сервер передал `Content-Length`, а соединение оборвалось раньше, ответ считается неполным и это ошибка.
- При ошибке сети, HTTP-ошибке (4xx/5xx), некорректном или неполном ответе скрипт печатает её и завершается с кодом 1.
